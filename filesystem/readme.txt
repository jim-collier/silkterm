This is an example filesystem structure. Optionally, you can copy/paste it to your own filesystem to create default files.

home/ mirrors a user home directory ($HOME) - e.g. home/.config/silkterm/wallpapers/ is where wallpaper images go, and rotation picks from it. (That directory was previously named "backgrounds", which still works; the home directory itself was previously named literally "~", which risked shell mishaps.)
